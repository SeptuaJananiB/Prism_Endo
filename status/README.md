# Project status board — open the HTML files in a browser (or the Excel file)

| Open this | Shows |
|---|---|
| STATUS_BOARD.html | All three tables on one page |
| COMPLETED.html | Finished work + evidence |
| IN_PROGRESS.html | What is running now |
| PENDING.html | Not started yet, with priority |
| STATUS_BOARD.xlsx | Same three tables in Excel (one sheet each) |

Edit `data/*.csv`, then run `python scripts/update_status_board.py` to refresh all of them.
